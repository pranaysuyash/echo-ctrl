# Contributing to EchoCtrl

Thank you for your interest in contributing to EchoCtrl!

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/yourusername/echo-ctrl.git`
3. Create a branch: `git checkout -b feature/your-feature-name`
4. Follow the setup instructions in README.md

## Development Workflow

1. Make your changes
2. Test your changes thoroughly
3. Ensure code follows the existing style
4. Update documentation if needed
5. Commit with clear, descriptive messages
6. Push to your fork
7. Create a pull request

## Code Style

- Use TypeScript for all new code
- Follow the existing code structure
- Use meaningful variable and function names
- Add comments for complex logic
- Use Prettier for formatting (already configured)

## Testing

Before submitting a PR:
- Test your changes manually
- Ensure the application builds: `npm run build`
- Check for TypeScript errors: `npx tsc --noEmit`

## Pull Request Guidelines

- Keep PRs focused on a single feature or fix
- Include a clear description of changes
- Link to any related issues
- Update documentation if needed
- Be responsive to feedback

## Reporting Issues

When reporting issues:
- Use a clear, descriptive title
- Describe the expected behavior
- Describe the actual behavior
- Include steps to reproduce
- Include environment details (OS, Node version, etc.)
- Include relevant logs or screenshots

## Questions?

Feel free to open an issue for questions or discussions.

Thank you for contributing to EchoCtrl!
